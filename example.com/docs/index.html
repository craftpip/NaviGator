API Reference

Complete reference for the widgets.js library API. This covers core functions, widget instance methods, events, types, and migration notes.

Tip: Use getWidget instead of keeping your own map of instances — the library maintains it internally and cleans up on destroy.

createWidget(id, options)

Creates a new widget instance and registers it with the internal store.

Signature

function createWidget<T extends WidgetType>(
  id: string,
  options: WidgetOptions<T>
): Widget<T>

Parameters

NameTypeRequiredDescription
id string Yes Unique identifier for this widget instance. Must not be empty. Thrown on DuplicateWidgetError if already registered.
options.type string Yes Widget type: "line" | "bar" | "pie" | "table" | "card" | "custom"
options.data unknown No Initial data payload. Shape depends on widget type.
options.container HTMLElement | string No DOM element or CSS selector to mount into. If omitted, render() must be called with an explicit target.
options.theme ThemeConfig No Color scheme, font stack, and spacing overrides. Falls back to the global theme.
options.lazy boolean No Default false. When true, the widget defers rendering until it enters the viewport (IntersectionObserver).
options.onReady () => void No Callback fired after the first render completes.

Returns

A Widget instance — see Widget instance methods below.

Errors

  • DuplicateWidgetError — the id is already registered
  • InvalidTypeError — the type string is not a known widget type
  • TypeError — id is not a string or options is not an object

Example

import { createWidget } from 'widgets';

const chart = createWidget('chart-1', {
  type: 'line',
  data: {
    labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
    datasets: [{ label: 'Revenue', values: [12000, 15000, 18000, 22000, 19000] }]
  },
  container: '#chart-container',
  theme: { primary: '#0366d6', fontFamily: 'Inter, sans-serif' },
  lazy: true,
  onReady: () => console.log('Chart mounted')
});

chart.render();
Performance note: Creating many widgets in a loop? Use createWidgets(ids, options) (batch variant) to share a single DOM reconciliation pass.

getWidget(id)

Returns a reference to an existing widget instance by its id.

Signature

function getWidget<T extends WidgetType>(id: string): Widget<T>

Parameters

NameTypeRequiredDescription
id string Yes The unique id passed to createWidget().

Returns

The matching Widget instance. Each instance exposes render(), update(data), destroy(), on(), off(), and getState().

Example

import { createWidget, getWidget } from 'widgets';

createWidget('chart-1', { type: 'line', data: [1, 2, 3] });
const widget = getWidget('chart-1');
widget.update({ data: [3, 2, 1] });
console.log(widget.isMounted()); // true

Errors

  • UnknownWidgetError — the id was never created or was destroyed
  • TypeError — id is not a string

destroyWidget(id)

Destroys a widget, removes its DOM, and frees internal memory.

Signature

function destroyWidget(id: string): boolean

Parameters

NameTypeRequiredDescription
id string Yes The widget id to destroy.

Returns

true if the widget existed and was destroyed. false if the id was not found (no-op).

Side effects

  • Removes all event listeners attached via on()
  • Unmounts the DOM if mounted
  • Fires a destroy event before cleanup
  • Emits a destroy event on the global event bus

Example

import { destroyWidget } from 'widgets';

const removed = destroyWidget('chart-1');
console.log(removed); // true
console.log(getWidget('chart-1')); // throws UnknownWidgetError

listWidgets(filter?)

Returns all registered widget instances, optionally filtered.

Signature

function listWidgets(filter?: {
  type?: WidgetType;
  mounted?: boolean;
}): WidgetInfo[];

Returns

An array of WidgetInfo objects: { id, type, mounted, createdAt, dataSize }.

Example

import { listWidgets } from 'widgets';

const all = listWidgets();
// [
//   { id: 'chart-1', type: 'line', mounted: true, createdAt: ..., dataSize: 1200 },
//   { id: 'table-1', type: 'table', mounted: false, createdAt: ..., dataSize: 45000 },
// ]

const mounted = listWidgets({ mounted: true });
const charts = listWidgets({ type: 'line' });

Widget Instance Methods

Every widget instance returned by createWidget or getWidget exposes the following methods:

render(target?)

Mounts or re-renders the widget into a DOM target.

widget.render();               // uses the container from createWidget
widget.render('#new-target');  // re-mount to a different element

update(data)

Merges new data into the widget's state and triggers a re-render. Supports partial updates — only the changed keys are reconciled.

// Update just the data
widget.update({ data: [5, 4, 3, 2, 1] });

// Update data and theme
widget.update({
  data: [10, 20, 30],
  theme: { primary: '#e36209' }
});

// Partial dataset update (line chart)
widget.update({
  datasets: [{ label: 'Revenue', values: [12, 18, 24] }]
});

on(event, handler)

Subscribes to a widget event. Returns an unsubscribe function.

const unsub = widget.on('click', (event) => {
  console.log('Clicked:', event.dataPoint);
});

// Later:
unsub();

off(event, handler)

Removes a specific event listener. Prefer the unsubscribe function from on().

getState()

Returns a frozen snapshot of the widget's internal state: { id, type, data, mounted, renderCount, lastUpdated }.

const state = widget.getState();
console.log(state.renderCount); // 14
console.log(state.lastUpdated); // 1692847200000

Event Reference

All events can be listened to via widget.on() or globally via Widgets.on().

EventPayloadDescription
ready{ id }Fired after the first render completes.
update{ id, data, diff }Fired after every data update.
click{ id, dataPoint, element }User clicked a data point (charts, tables).
hover{ id, dataPoint }User hovered a data point.
error{ id, error, phase }Render or data error. Phase: "render" | "data" | "mount".
destroy{ id }Widget is about to be destroyed.
resize{ id, width, height }Container was resized (debounced 100ms).
visible{ id }Widget entered the viewport (lazy mode).
hidden{ id }Widget left the viewport (lazy mode).

Migration from v1

Deprecated in v2: createWidget(id, type, data) — the 3-argument overload is removed. Use the options object form: createWidget(id, { type, data }).
Migration path: Replace all createWidget('x', 'line', [1,2,3]) calls with createWidget('x', { type: 'line', data: [1,2,3] }). The old form was removed in v2.0.0.
Deprecated in v2: widget.setData(data) — use widget.update({ data }) instead.
Removed in v2: Widgets.renderAll() — widgets now auto-render when a container is provided.

Breaking changes in v2

  • Minimum Node.js version: 18.0 (was 14.0)
  • IE11 is no longer supported
  • Widget.render() now returns a Promise<void> (was void)
  • The data option is no longer mutated — updates go through update()
  • Error events now include a phase field
  • Theme config renamed colors → colorMap (old name still works with a warning)
