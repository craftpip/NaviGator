getWidget

Returns a reference to an existing widget instance by its id. Throws if the id was never registered.

Signature

getWidget(id: string): Widget

Parameters

NameTypeRequiredDescription
idstringyesThe unique id passed to createWidget().
optionsobjectnoReserved for future options. Currently unused.

Returns

The matching Widget instance. Each instance exposes render(), update(data) and on(event, handler).

Example

import { createWidget, getWidget } from 'widgets';

createWidget('chart-1', { type: 'line', data: [1, 2, 3] });
const widget = getWidget('chart-1');
widget.update({ data: [3, 2, 1] });
console.log(widget.isMounted()); // true

Errors

  • UnknownWidgetError — the id was never created
  • TypeError — id is not a string
Tip: use getWidget instead of keeping your own map of instances; the library maintains it internally and cleans up on destroy.

Browser compatibility

Supported in all evergreen browsers. IE11 is not supported since v2.0.
