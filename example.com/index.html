Welcome to the test site

This site is a comprehensive HTML playground for testing web extraction tools. Every page simulates a real-world layout — news articles, dashboards, social feeds, docs, e-commerce, forms, multi-step flows, and more — all with fictional content in a realistic "Testville / CloudStack" world. No real data, no real companies.

Edge Cases & Stress Tests

The Daily Chronicle

Clean, semantic news page with article, nav, aside, footer. Readability-friendly — should extract cleanly without hints.
Readability-friendlySemantic HTML

TrendyBlogz — Div Soup

1998-style div-soup portal: nested divs, no semantic elements, mixed content, sidebar noise. Readability-hostile by design.
Readability-hostileDiv soup

ChaosHub — Randomized

Page that randomizes itself on every load: random headings, paragraphs, tables, links, images, and layout. Tests extraction stability.
UnpredictableNon-deterministic

LiveWire — Never-Stop Updating

Live stock ticker, live scores, and a live blog that continuously appends new entries via JavaScript. Content is always changing.
Dynamic contentAuto-updating

Soft 404

A page-not-found page with a search box, suggested links, and helpful copy. Looks like a real page but is actually a 404.
Soft 404Search box

PremiumBeat — Paywall

Article with the first 2 paragraphs visible, then a blurred overlay with a subscription prompt. Content is in the DOM but hidden.
PaywallHidden content

RecipeNest — Cookie Banner

Full recipe article with a fixed cookie consent banner at the bottom. Content is accessible but partially obscured by the overlay.
Cookie bannerFixed overlay

WidgetDash — SPA

Content rendered entirely by JavaScript. No server-rendered HTML — the page body is empty until JS executes. Tests JS-dependent extraction.
JavaScript-renderedSPA

ScrollFeed — Infinite Scroll

Content loads on scroll via IntersectionObserver. Only the first batch is in the DOM initially — more appears as you scroll down.
Lazy-loadedIntersectionObserver

SlowScroller — Lazy Load

Images and text blocks lazy-load on scroll. Below the fold, elements are placeholders until they enter the viewport.
Lazy imagesScroll-triggered

SlowServe — Staged Loading

Content appears in stages with random delays. Header loads first, then body content after 1–3 seconds, then sidebar.
Staged loadRandom delays

A page that redirects to another URL after 3 seconds. Tests redirect detection and follow behavior.

About this site

All pages are fictional. The world is called "Testville" (news, reference, profiles) and "CloudStack" (SaaS product, onboarding). No real companies, no real data. Pages range from static HTML to fully JavaScript-rendered SPAs.

  • 28 page types across 10 categories
  • Character range: 9K (step pages) to 36K (interactive help center)
  • Extraction patterns: Readability-friendly, Readability-hostile, tables-only, social, docs, forms, multi-step flows
  • Edge cases: paywalls, cookie banners, SPAs, infinite scroll, lazy load, staged loading, chaos, redirects, soft 404s
  • Interactive elements: tabs, accordions, toggles, modals, forms, multi-page wizards, dynamic content
