Test sites catalog

Realistic page types for exercising extraction — each folder simulates a different pattern of the real internet:

  • The Daily Chronicle — clean, semantic news (Readability-friendly)
  • TrendyBlogz — 1998 div-soup portal (Readability-hostile)
  • WidgetDash SPA — content rendered entirely by JavaScript
  • ScrollFeed — content loads on scroll (IntersectionObserver)
  • PremiumBeat — article blurred behind a paywall overlay
  • RecipeNest — full article with a fixed cookie banner
  • GadgetHub — product page with specs table and reviews
  • Chirp profile — social profile with stats and a feed
  • widgets.js docs — docs page with sidebar, code, and tables
  • Testpedia — Wikipedia-style article with infobox
  • VidStream — video page with description, comments, sidebar
  • TestBank Markets — dense option-chain data tables
  • The Testville Ledger — rich blog: featured posts, tags, comments, exit-intent popup
  • Ledger article — full essay with author box and nested comment thread
  • ChaosHub — a page that randomizes itself on every load
  • LiveWire — markets, scores, and a live blog that never stop updating
  • SlowScroller — images and text lazy-load on scroll
  • SlowServe — content appears in stages with random delays
  • Soft 404 — the page-not-found pattern with search
  • Redirect — a page that redirects elsewhere after 3 seconds

About this site

All pages are plain static HTML with no JavaScript. Content loads immediately, which makes timing simple. Use it to verify that the extractor keeps headings, paragraphs, lists, tables and links clean.
