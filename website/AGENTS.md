# Agents

## Console Screenshots

When taking console screenshots for the landing page:

- **Viewport width: 1440, height: 900** — no black borders
- **fullPage: false** — viewport only, not full page
- **Quality: 80** — good balance of size and clarity
- Toggle Dark/Light by clicking the actual button (not `classList.toggle`)
- Copy from container: `docker cp navigator:/tmp/console-*.jpg /www1/navigator/website/public/`
